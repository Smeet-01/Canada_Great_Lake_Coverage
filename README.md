# Canada_Great_Lake_Coverage

A **Power BI** forecasting and anomaly detection analysis of historical ice coverage across the Great Lakes of Canada (1973–2020), using data from Data.world.

## Key Questions Answered
1. **What is the projected average ice coverage in 2030?**
   - Power BI's built-in forecasting projects an average ice coverage of **55.1** for 2030.
2. **Which lake contributed most to data anomalies?**
   - **Lake Erie** accounted for the majority of detected anomalies.

## Files
- `Forecast and Anomaly Detection.pbix`: Power BI report for 2030 forecasting and anomaly detection.
- `Trend Identification.pbix`: Power BI report for historical trend analysis.
- `Great Lakes Historical Ice Coverage 1973 to 2020.xlsx`: Source dataset.

## Usage
Open either `.pbix` file in **Power BI Desktop** to explore the interactive visuals.
